# Site Watch: проверка перед публикацией

Режим: antislop во время переделки, выбран владельцем.
Направление: операционная панель для владельца семи сайтов, компактный отчёт наблюдений.
ENERGY 2 / RHYTHM 2 / MOTION 1. Причины визуальных решений записаны в DESIGN.md.

## Исправления

- В targets.json семь адресов из сообщения владельца. Старые четыре ID не изменены.
- HTTP-проверка общая для FastAPI и Pages: только 2xx считается успехом, редиректы ограничены хостом и количеством, сетевые ошибки сохраняются.
- Статусы и история Pages читаются из одного файла. Последний успешный снимок остаётся виден при ошибке обновления; данные старше трёх часов помечаются.
- 401/403/429 и непроверенные редиректы не называются подтверждёнными сбоями сайта.
- Исправлены сортировка и дубли наблюдений, сохранены ID сайтов при чтении строк SQLite.
- Импорт разделён по сайту и источнику. Пустые позиции не превращаются в ноль. Ошибочный CSV и превышение лимита не затирают прежние данные.
- Таблица запросов получила поиск, сортировку, страницы и удаление импорта. Поиск не пересоздаёт свой input.
- Страница на обычном статическом localhost не пытается обращаться к отсутствующему FastAPI.
- Работают обе темы, закрытие подробностей через Escape и возврат фокуса.

## Границы проверки

Это HTTP-монитор, не полноценный браузерный тест чужих сайтов. Не проверяет оплату, формы или авторизацию на них. SEO API не подключены. Временная SQLite для браузерного теста не заменяла пользовательскую базу. Существующие права Actions и механизм хранения истории не расширялись.
