# Заблокированная проверка не означает недоступность сайта

Исправление после замечания владельца о работающем GoldenFix.

- HTTP 401/403/429, непроверенные редиректы и неизвестные результаты исключены из знаменателя доли успеха.
- Рядом с процентом показано, сколько наблюдений учтено из общего количества.
- Если все наблюдения неопределённые, доля успеха и эпизоды ошибок отображаются как «Нет оценки», а не 0%.
- В сводке разделены успешные ответы, ошибки проверки и сайты без оценки.
- Неопределённое наблюдение не считается подтверждением восстановления после ошибки.
- История остаётся неизменной: пересчитывается её представление, а не записанные результаты.

Проверка: 37 Python-тестов и 12 JS-тестов прошли. Отдельная регрессия с 37 ответами 403 подтверждает отсутствие ложного 0%. Смесь 503/401/429/неизвестно/503/200 даёт 1 успешное наблюдение из 3 учтённых, остальные 3 исключены, эпизод ошибки остаётся один.

R-17 / C-5 PASS: неопределённые результаты не выдаются за доступность или простой.
R-03 PASS: ширина документа 375 при viewport 390, без переполнения.
R-25 PASS: существующие две палитры проходят test_design.py.
R-26 / R-32 PASS: карточка открывается прежним нативным контролом, новые контролы не добавлены.
R-35 PASS: исправленная карточка GoldenFix проверена в браузере.
R-31 PASS: переносу разрешены длинные подписи статуса и счётчиков, чтобы объяснение помещалось на мобильном экране.

Это уточнение заменяет прежнюю трактовку процента успеха в отчёте verification-2026-10-04.md.

При проверке реальной опубликованной истории GoldenFix обнаружены 36 ответов 403 и два ConnectTimeout. Для этой комбинации добавлена отдельная регрессия: результат «Нет оценки». Сетевые ошибки без HTTP-ответа также исключены из доли успеха, оставаясь видимыми в журнале. Ответы с подтверждённой HTTP-ошибкой, например 503, продолжают учитываться. JS-тестов теперь 13. Файлы интерфейса и аналитики получили версии URL для обновления кеша.
