Успех означает HTTP 2xx в момент проверки. Это не проверка форм, оплаты или работы JavaScript. 403 и 429 показываются отдельно: отказ боту не доказывает сбой сайта.

Запросы из поиска

Клики, показы и позиции из вашего CSV. Доступ к аккаунту поисковика не требуется.

Сначала загрузите экспорт запросов

Нужны колонки «Запрос», «Клики» и «Показы». Позиция необязательна. Поддерживаются CSV из Google Search Console и Яндекс Вебмастера.

Каждый сайт и источник имеют отдельный импорт. CSV хранится только в памяти вкладки и исчезнет после обновления страницы. Файл никуда не отправляется. Период задаётся при экспорте из поисковика.
