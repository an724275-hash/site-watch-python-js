# Site Watch

Небольшой монитор доступности сайтов: FastAPI выполняет реальные HTTP-проверки, SQLite хранит историю, JavaScript обновляет панель без перезагрузки. Для каждого сайта видны статус, время последней проверки, задержка и последние 24 результата.

## Запуск

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements-dev.txt
uvicorn app:app --reload
```

Откройте `http://127.0.0.1:8000`. Проверки идут при запуске, затем раз в пять минут. Кнопка «Проверить» запускает дополнительную проверку. Для тестов: `pytest -q`.

Список сайтов хранится в `targets.json`; после изменения перезапустите сервер. Интерфейс не принимает произвольные адреса. Это сознательное ограничение для безопасной демонстрации. Для публичного развертывания используйте только доверенный файл конфигурации и ограничьте доступ к API ручной проверки. Показатели не подставлены: до первого ответа сервера панель показывает ожидание.

Переменные окружения: `SITE_WATCH_DB`, `SITE_WATCH_TARGETS`, `SITE_WATCH_INTERVAL` (секунды, минимум 30).
