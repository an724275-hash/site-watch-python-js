# Site Watch

Небольшой монитор доступности сайтов: FastAPI выполняет реальные HTTP-проверки, SQLite хранит историю, JavaScript обновляет простую панель без перезагрузки. На странице видны статус каждого сайта и время последней проверки. История последних 24 проверок, задержка и HTTP-код доступны через локальный API `/api/targets`.

[Открыть упрощённую страницу на GitHub Pages](https://an724275-hash.github.io/site-watch-python-js/). GitHub Actions проверяет адреса примерно каждые 30 минут и публикует снимок результатов. Расписание GitHub Actions может выполняться с задержкой; дата последней проверки указана на странице. Pages не запускает FastAPI, поэтому ручная проверка и полная история доступны при локальном запуске.

## Запуск

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements-dev.txt
uvicorn app:app --reload
```

Откройте `http://127.0.0.1:8000`. Проверки идут при запуске, затем раз в пять минут. Дополнительную проверку можно запустить через `POST /api/targets/{id}/check`. Для тестов: `python -m pytest -q`.

Список сайтов хранится в `targets.json`; после изменения перезапустите сервер. Интерфейс не принимает произвольные адреса. Это сознательное ограничение для безопасной демонстрации. Для публичного развертывания используйте только доверенный файл конфигурации и ограничьте доступ к API ручной проверки. Показатели не подставлены: до первого ответа сервера панель показывает ожидание.

Переменные окружения: `SITE_WATCH_DB`, `SITE_WATCH_TARGETS`, `SITE_WATCH_INTERVAL` (секунды, минимум 30).
